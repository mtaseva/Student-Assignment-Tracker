# 🎓 Систем за следење на студентски задачи

Веб-базиран систем кој им помага на студентите да ги организираат нивните задачи, следат рокови и учествуваат во академски дискусии.

## 📌 Опис на проектот

Оваа апликација им овозможува на студентите да:
- Се регистрираат и најавуваат безбедно
- Креираат и прегледуваат задачи и обврски
- Управуваат со информации поврзани со предмети
- Учестуваат во дискусионен форум
- Гледаат персонализирана контролна табла со сите задачи и рокови

## 🛠️ Користени технологии

- **Backend:** PHP (стандардна имплементација)
- **Frontend:** HTML, CSS
- **База на податоци:** MySQL
- **Дизајн:** Прилагодено лого и стилови

## 📂 Структура на проектот

/assets → Икони и прилагодени стилови

/includes → PHP скрипти за база и логика

/public → PHP страници за корисници (контролна табла, најавување, форум итн.)

/views → Статични содржини (страница „За нас“)

studentassignmenttracker1.sql → MySQL шема за базата на податоци

## 🚀 Почеток со користење

### Важни забелешки

- PHP 7.x или понова верзија  
- MySQL или друг компатибилен СУБП  
- Веб-сервер (на пр. Apache)

### Инсталација

1. Клонирајте или преземете го овој репозиториум.
2. Увезете ја базата на податоци со фајлот `studentassignmenttracker1.sql`.
3. Конфигурирајте го фајлот `/includes/db.php` со вашите податоци за пристап до базата.
4. Стартувајте ја апликацијата локално или на сервер со поддршка за PHP.

### Пример конфигурација (`/includes/db.php`)


php

$host = "localhost";

$db = "student_assignment_tracker";

$user = "root";

$pass = ""; // лозинка за вашата база на податоци
